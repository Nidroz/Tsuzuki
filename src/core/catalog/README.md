# src/core/catalog

The `CatalogProvider` interface with its normalized types, the shared http layer, the failure monitor, and one subfolder per provider.
Adapters parse every response with Zod, set `isAdult`, go through the rate limiter and never filter content in requests (ADR-0004); a provider host is written only in its adapter.
`catalog-provider.ts` holds the interface and normalized types (no Zod). A provider exposes its `namespace`, the id namespace of every `MediaKey` it returns and accepts (catalog query keys are built from it), and an `instanceId` naming the configured server in error reports, never a url (ADR-0013).
`search-params.ts` normalizes `SearchParams` for the search query key; `image-url.ts` keeps a provider image url only when it is https on an allowed cdn host (`toAllowedImageUrl`, plain string checks).
`catalog-failure-monitor.ts`: `monitorCatalogProvider(provider, { reporter, now? })` wraps a provider and reports sustained failures to the `ErrorReporter`: 3 counted failures since the last success, within 2 minutes of the latest one, give one `CatalogProviderFailureError` per kind (`server_error`, `rate_limited`, `client_error`, `timeout`, `malformed_response`) every 30 minutes at most, tagged with the instance id and the kind only. Network errors, aborts and input `RangeError`s are neither counted nor resetting. Values and errors pass through unchanged.
`jikan/` is the adapter of every Jikan v4 compatible instance, all in the `mal` namespace: `createJikanCatalogProvider(instance, options?)` builds its own http client, so its own limiter, from the instance's rate limit. `jikan-instances.ts` holds `TENRAI_INSTANCE` (the default, `TENRAI_RATE_LIMIT`), `selfHostedJikanInstance(baseUrl)` (`SELF_HOSTED_JIKAN_RATE_LIMIT`, the public Jikan's documented limits) and `jikanInstanceFor(appEnv.jikanBaseUrl)`; the policies and their derivations are in `jikan-rate-limit.ts`. Deterministic request urls under the instance base url and input guards, the Tenrai query length and genre count limits included (`jikan-urls.ts`), Zod schemas of the payloads (`jikan-schemas.ts`), field normalization (`jikan-fields.ts`) and the mapping to the normalized types, `isAdult` included (`jikan-mappers.ts`). Covers come from the MyAnimeList cdn on every instance. `__fixtures__/` holds test payload builders, msw handlers (Tenrai by default, any base url on request) and recorded Tenrai responses.
`http/` is the http client every adapter sends its requests through (`createCatalogHttpClient`, one per provider instance): a token bucket rate limiter (`rate-limiter.ts`), in-flight dedup of identical urls (`in-flight-dedup.ts`), retries with exponential backoff and jitter on 429, 5xx, network errors and timeouts, honoring Retry-After (`retry-policy.ts`), and abort helpers (`abortable.ts`). Its errors live in `src/core/errors/catalog-errors.ts`.
`src/core/` never imports React Native, Expo modules or NativeWind.
